Åndedrætsforløb

Åndedrætsforløb på hold — 5 x 1,5 t.

I dette forløb arbejder vi med vores åndedræt gennem konkrete øvelser der åbner og bevidstgør vores vejrtrækning. Målet er at skabe en kropslig forståelse af, hvordan vi kan justere og forbedre vores åndedræt.

Jeg inddrager relevant teori, så I får en dybere indsigt i, hvad der sker i kroppen og hvorfor øvelserne virker.

  1. Introduktion og kropslig bevidsthed

    • Mærk dit åndedræt
    • Åndedrætsfrekvens og hvad der kan påvirke vores daglige åndedræt
    • Hvordan vi giver vores åndedræt bedre betingelser og udnytter vores fulde potentiale
    • Konkrete øvelser

  2. Grundlæggende åndedrætsarbejde

    • Næse/mund
    • Diafragma
    • Spændinger i bindevævet/bryst og mave
    • 3D åndedrættet
    • Øvelser

  3. Nervesystemet

    • Når vi er påvirket mentalt af stress, sorg, mangel på søvn mv.
    • Hvordan skaber vi ro i vores nervesystem
    • Øvelser

  4. CO2-tolerance

    • Energi. Hvordan får vi mere energi til kroppen hvis vi er udmattede og trætte
    • Øvelser

  5. Opsamling

Forløbet giver dig konkrete redskaber du kan bruge i din hverdag:

  • Mere ro i nervesystemet
  • Bedre søvn
  • Mindre stress
  • Mere energi
